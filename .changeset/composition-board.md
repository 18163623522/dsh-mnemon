The memory components are composed on one Memory composition board on the `dsh-mnemon` page under Plugins, drawn from what the installed components declare, so shipped components and installed extensions are named, related and configured the same way. The main Strategy is one selector with each Strategy's description, however many are installed; every other role gets a group with a count of what is on, and a new role gets a group of its own. Each row shows the component's state as DSH's component list shows it, link chips naming the components it relates to, a gear when it has settings of its own, and its switch; a memory layer shares one switch with its Source component. Every switch applies at once: turning a component on brings what it needs and turns off what cannot run beside it, turning one off takes along what depends on it, choosing a main Strategy turns the others off, and the last running Source stays on. A problem line appears only while memory is not composed as chosen, with the one switch that fixes it. A change that moved more than its own row is reported with Undo, a change made elsewhere with Show, and a refused one with Retry. The component's page lists its relations, what its switch would move, and the options it declares, such as General's resident sources and Active capture's recording targets, which can now be configured. Enhancements for another main Strategy wait in a closed group, and a search appears once many components are installed. The Memory System shows a layer whose Source component is off as off. Configuration keys, stored values and data are unchanged.

记忆组件改在“插件”中 `dsh-mnemon` 页面的“记忆组合”面板中组合，面板由已安装组件的声明生成，随附组件与已安装的扩展按同一种方式命名、关联和配置。主策略始终是一个带说明的选择器，无论安装了几个；其他角色各成一组并显示已开启的数量，新的角色自成一组。每行显示与 DSH 组件列表一致的状态、点名相关组件的关联标签、有自己设置时的齿轮，以及开关；记忆层与它的 Source 组件共用一个开关。每个开关立即生效：开启组件会一同开启它需要的组件、关闭不能与它同时运行的组件，关闭组件会一同关闭依赖它的组件，选择主策略会关闭其他主策略，最后一个运行中的来源保持开启。只有记忆没有按所选方式组合时才出现问题提示，并给出唯一的修复开关。影响了其他行的修改提供“撤销”，在别处做出的修改提供“查看”，被拒绝的修改提供“重试”。组件页列出它的关系、开关会带动的组件以及它声明的选项；“通用”的常驻来源、“主动记录”的记录目标等选项现在可以配置。适用于其他主策略的增强收在折叠分组中，组件较多时出现搜索。记忆系统会把 Source 组件已关闭的层显示为“已关闭”。配置键、已保存的值与数据不变。
