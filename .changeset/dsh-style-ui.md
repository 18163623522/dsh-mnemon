The memory workspace, Settings and conversation controls follow DSH's own design: DSH theme tokens and the DSH Button, Switch, Menu selector, Tag, StateDot, Input and Modal specifications replace the bespoke blue buttons, green switches, colored card stripes and sub-11px monospace labels. Settings → Memory System is organized as DSH preference rows in six groups (Interface, Storage, Memory layers, Strategy, Memory providers, Background tasks); every general storage setting now sits under Storage, with one Data directory field that is the default when empty, and Mnemon Native is the first Provider card, keeping only its embedding settings. Status lists Mnemon Native as the first row of one Memory providers list. The Plugins page composition uses the same rows. A pending-changes bar stays at the bottom of Settings, the dialog close control is named Close, and the version dialog no longer overflows with long install paths. Configuration keys, stored settings and data are unchanged.

记忆工作台、设置与对话内控件改用 DSH 自身的设计：以 DSH 主题令牌以及 DSH 的 Button、Switch、Menu 选择器、Tag、StateDot、Input 与 Modal 规格，替换原来自绘的蓝色按钮、绿色开关、卡片彩色边条和小于 11px 的等宽标签。“设置 → 记忆系统”按 DSH 偏好行分为六组（界面、存储、记忆层、策略、记忆 Provider、后台任务）；通用存储设置全部归入“存储”，只保留一个“数据目录”输入框（留空即默认目录）；Mnemon Native 作为第一张 Provider 卡片，只保留其嵌入设置。状态页在同一个“记忆 Provider”列表中把 Mnemon Native 列为第一行。插件页的组合控件使用相同的行。设置页有未保存修改时底部显示保存栏，弹窗关闭按钮改名为“关闭”，版本弹窗不再被长安装路径撑宽。配置键、已保存设置与数据不变。
