New main Strategy: the General strategy. It admits every available Source within the View limits, keeps working-context Sources resident by default and the others on demand, and gives the model one memory protocol for the View's named tools, Routes and Actions. Resident Sources and additional guidance are configurable, and the standard selection, projection and capture enhancements apply to it. Requires a `dsh-mnemon` release with the standard View extension SDK.

新增通用策略。它在 View 限额内接入全部可用 Source，默认常驻工作上下文类 Source、其余按需读取，并为模型提供一套使用 View 具名工具、Route 与 Action 的记忆协议。可配置常驻 Source 与附加指引，标准的 selection、projection、capture 增强均可作用于它。需要包含标准 View 扩展 SDK 的 `dsh-mnemon` 版本。
