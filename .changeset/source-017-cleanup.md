Internal cleanup for DSH 0.1.7: require the DSH Loader surface, read the required locale service directly, reuse the extension SDK input helpers and remove unused internal helpers. Memory Spaces copies ids through the DSH UI primitives' clipboard helper and declares that peer. Public types, data and behaviour are unchanged.

面向 DSH 0.1.7 的内部清理：要求 DSH Loader 接口、直接读取必需的 locale 服务、复用扩展 SDK 的输入工具并移除未使用的内部辅助代码。记忆空间改用 DSH UI primitives 的剪贴板工具复制 ID，并声明该 peer 依赖。公开类型、数据与行为不变。
