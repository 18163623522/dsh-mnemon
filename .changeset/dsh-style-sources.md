The default Source pages use the DSH component look: hairline cards without provider stripes or gradients, DSH Tags and state dots, the DSH Switch for space activation, segmented filters, and text no smaller than 11px. Memory Spaces pages under its tabs title their sections at the group heading scale, entity capability cards mark unsupported Providers as idle rather than failed, row delete and disconnect actions use the DSH card delete style, and the create dialog form uses its own layout class again.

默认 Source 页面采用 DSH 组件外观：细描边卡片（去掉 Provider 彩色边条与渐变）、DSH 标签与状态点、用 DSH 开关激活空间、分段筛选，文字不小于 11px。记忆空间各 Tab 下的页面以分组标题的层级命名其区块；实体能力卡片把不支持的 Provider 标为闲置而非故障；行内的删除与断开使用 DSH 卡片删除样式；创建对话框表单重新使用自己的布局类。
