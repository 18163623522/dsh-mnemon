The Mnemon CLI is presented as optional: only Mnemon Native needs it. Status shows the Native card once its CLI is installed or a Native space exists; the version dialog lists dsh-mnemon first and a missing CLI as optional; the configuration marks the CLI as not installed and disables the embedding test that runs it; `/mnemon status` reports the CLI as optional. The READMEs and guides describe the CLI as the route to Mnemon Native.

Mnemon CLI 改为可选组件，只有 Mnemon Native 需要它。状态页在安装 CLI 或存在 Native 空间时才显示 Native 卡片；版本对话框先列出 dsh-mnemon，未安装的 CLI 显示为可选；配置页标记 CLI 未安装，并停用依赖它的向量测试；`/mnemon status` 把 CLI 报告为可选。README 与指南把 CLI 描述为使用 Mnemon Native 的途径。
